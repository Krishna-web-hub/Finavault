Layer 8 — SaaS Security

Security is the Architecture

Not a bolt-on. Every step from upload to answer has independent, fail-closed protection.

The Core Security Invariant

ACL Clearance (can this user retrieve a chunk) and Externalization Policy (can this chunk's content ever reach the LLM) are two independent checks. A Compliance Officer can be fully authorized to retrieve a restricted memo without that memo's text ever leaving the system boundary.

1
Ingestion — Encrypt Before Storage
Local embeddings (bge-small-en-v1.5) → AES-256-GCM per-chunk envelope encryption with deterministic AAD binding (document_id:chunk_index) → Only ciphertext + wrapped keys stored in Qdrant and PostgreSQL. Zero plaintext persisted anywhere.
2
Retrieval — ACL Filter + Silent Drop
Vector search returns candidates. Each hit: (a) check org isolation — cross-org fails silently, (b) check role clearance — lower-clearance user cannot even infer that a restricted document matched. Unauthorized chunks dropped silently, never surfaced as a denial.
3
Externalization Gate — Withheld Before LLM
RESTRICTED classified chunks are withheld at the point content would be assembled into a tool result — before it enters any LLM prompt. A placeholder is shown. The classification ceiling is tracked for a second post-hoc gate in Compliance.
4
Prompt Injection Defense — Dual Layer
wrap_untrusted_content() delimits retrieved text and neutralizes any embedded delimiter tags (preventing tag-escape attacks). detect_injection_attempt() provides a second independent heuristic signal scanning 16+ regex patterns including DAN, jailbreak, system override.
5
Output Guardrails — PII, Citations, Semantics
Every draft answer: (a) regex PII/secret scan + redaction, (b) verbatim citation grounding check — hallucinated quotes fail, (c) LLM semantic review with fail-closed default (unreachable LLM = BLOCK). All three must pass before the user sees a response.
6
Audit Trail — Tamper-Evident Hash Chain
Every query, retrieval, and compliance decision written to a SHA-256 hash-chained log. AuditLog.verify_chain() can detect any out-of-band insertion, deletion, or modification from that entry forward. Blocked responses are queued for compliance officer review.
